CH1 Extend Your Knowledge

Dylan Parisotto - 5/14/2026

Guideline 1.1 teaches you how to make sure that anything you can't read as text still has a text description so everyone, including people with disabilities, can understand it.

Guide 1.2 teaches you how to make sure that media like videos and audio are usable by people who can't see or hear them.

Guide 1.3 teaches you how to make sure content stays clear and understandable no matter how it's viewed or adapted for different users.

Guide 1.4 teaches you how to make sure content is clear and distinguishable so people can easily read, see, and hear it.
